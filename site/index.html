How It Works

Clean, Provider-Agnostic Architecture

A high-performance ASP.NET Core backend driving a modern React SPA via real-time streams and provider adapters.

STEP 01

Install & Configure CLIs

Keep using your favorite tools: Antigravity (`agy`), Claude Code, Gemini CLI, OpenAI Codex, OpenCode, or Copilot with your existing credentials and system configurations.

STEP 02

Launch AI Agent Hub

Start the lightweight self-hosted backend. The hub automatically detects installed providers and manages persistent workspace sessions.

STEP 03

Connect from Any Device

Open the web interface on your desktop, iPad, or mobile phone. Enjoy real-time agent output streaming, visual file diffing, and one-click approvals.

Security & Privacy First

Your Hardware, Your Keys, Zero Cloud Intermediary

Engineered from the ground up to guarantee that your proprietary code, master API tokens, and AI sessions never touch a third-party server.

Zero Credential Interception

AI Agent Hub never requests, captures, logs, or stores your provider API keys. Authentication is handled 100% natively by official vendor CLIs using your operating system's secure credential vault.

🛡️ Native OS Keychain Auth

100% Local & Self-Hosted

Runs entirely on your machine. There is zero telemetry, no analytics tracking, and no cloud proxy. Your source files, conversation context, and snapshots stay strictly on your local filesystem.

🔒 Zero Cloud Relays

Direct Encrypted Remote Access

Client browsers (laptops, phones, tablets) connect directly over your LAN with HTTPS/WSS. Use --safe-client <IP> to grant trusted admin permissions without exposing secrets to client devices.

🌐 Direct P2P / LAN HTTPS

Instant Launch

Up and Running in 30 Seconds

No complex containers or databases required. Single-command execution with .NET 10.

# 1. Clone the repository git clone https://github.com/rafaelhbrasil/AIAgentHub.git cd AIAgentHub # 2. Run the application (starts on https://localhost:5432) dotnet run --project src/AIAgentHub.Web
# Run on custom port without automatically opening browser dotnet run --project src/AIAgentHub.Web -- --urls "https://0.0.0.0:8080" --no-browser
# Install dependencies & start Vite frontend with Hot Module Reloading npm install npm run dev
