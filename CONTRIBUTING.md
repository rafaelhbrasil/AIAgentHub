# Contributing to AI Agent Hub

Thank you for your interest in contributing to AI Agent Hub!

To help keep the codebase consistent, maintainable, and secure, please review our official engineering documentation:

- 📖 **[Contributing Guide](docs/technical/ContributingGuide.md)** — Pull request lifecycle, branch naming strategy, commit guidelines, issue reporting, and review checklist.
- 📐 **[Development Standards](docs/technical/DevelopmentStandards.md)** — Coding conventions, C# / TypeScript style guides, async guidelines, and testing requirements.
- 🏗️ **[Architecture Guide](docs/technical/Architecture.md)** & **[ADRs](docs/technical/adr/)** — Architecture principles, domain models, and architectural decision records.

---

### Quick PR Checklist
- [ ] Code builds cleanly without compiler warnings (`dotnet build` & `npm run build`).
- [ ] All tests pass (`npm run test:all`).
- [ ] Clear and descriptive commit messages explaining what was changed and why.
- [ ] Relevant documentation in [`docs/`](docs/) is updated if behavior or architecture changed.
